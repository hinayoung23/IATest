# 能力与平台边界

本页是当前源码的能力入口。安装版本的可用功能应以 `iatest test capabilities`、`iatest test doctor` 和设备预检为准。功能实现与某个操作系统、设备或业务 App 的兼容范围分别判断。

## 功能矩阵

| 能力 | 当前实现 | 需要的条件 |
|---|---|---|
| API | 文档导入、场景规划、Markdown 用例、数据驱动、鉴权、Mock、夹具、确定性断言 | 授权的 HTTP 服务；生成时配置模型 |
| 浏览器 | Chromium CDP、Firefox WebDriver、Safari 常规模式；frame、页面、文件、滚动与局部视觉 | 已安装浏览器/驱动；受支持的网络策略 |
| 桌面 | macOS AX、Windows UIAutomation、Linux AT-SPI；语义操作、键盘、右键、拖拽、滚轮、窗口截图与视觉锚点 | 交互桌面、明确 PID/App 身份、系统授权 |
| GNOME Wayland | 显式门户模式、键鼠与限定窗口截图；独立进程授权、窗口绑定和撤销门禁 | 完整模式需要项目 GNOME 组件和两级授权；兼容基线为 GNOME 43.8 |
| Android | 原生输入、IME、多触点、WebView、媒体、交付和平台指标 | SDK/JDK、已授权 ADB、相应原生组件 |
| iOS | XCTest 原生操作、USB/独立 TLS、WKWebView、视频、局部视觉、启动及显式性能测量 | macOS/Xcode、开发者模式、受信任签名 Runner、对应设备权限 |
| 蓝牙 HID | 安卓作为 iPhone 键鼠；中文候选读回；显式托管与有限恢复监控 | 兼容的安卓蓝牙、iPhone 辅助触控、授权 ADB；输入时前台和解锁 |
| USB HID | 键鼠、绝对指针、拼音候选及触点报告的软件通道 | 配套 USB gadget/HID 硬件及目标系统识别 |
| 性能 | HTTP/事务、局域网分布式负载、协议会话负载、浏览器/客户端指标与门禁 | 授权服务、有限负载预算及对应采集环境 |
| 安全与无障碍 | 显式安全规则、有限爬取和验证链；自动检查与构建绑定人工复核 | 明确授权范围、必要身份与人工证据 |
| 数据与协议 | SQLite/PostgreSQL/MySQL 只读数据、数据质量、WebSocket、MQTT 3.1.1/5.0 QoS 0/1/2、结构化 gRPC | 对应服务；网络数据库需要可选依赖、TLS 与只读权限 |
| 编排与节点 | 有限 DAG、并发、类型化输出、资源互斥、远程节点、版本测试任务、TLS 与 etcd 协调 | 明确节点授权、证书及资源配置 |
| AI | 目标探索、计划固化、真实局部视觉、证据分析、知识治理、工具审计和预算 | 具有相应工具/图像能力的模型；业务断言独立验证 |

## UI 兼容范围

- Chromium 支持显式同源/跨进程 frame、开放/闭合 Shadow DOM、平面透视映射和局部视觉锚点。Firefox 支持原生 frame 与几何校验；Safari 采用显式 `navigation_only` 常规模式。
- WKWebView 需要 App 开启 inspectable、回环检查器、准确 App/PID 绑定和原生容器；支持嵌套 frame、视口缩放、平面透视和独立 CSS 变换。
- 桌面视觉通过实际图像模型定位后仍重新核对截图、目标和窗口绑定；模型建议不产生测试通过结论。
- GNOME 组件声明 43/44，真实兼容基线是 43.8、单显示器、100% 缩放。KDE、wlroots、其它 GNOME 版本以及多屏/DPI 配置需要单独验证，不能从 XWayland 的 DISPLAY 推断可用。

## 明确的限制

| 限制 | 可用替代或处理方式 |
|---|---|
| Safari 严格请求拦截不可用；常规模式不拦截网页后台请求 | 显式选择常规模式并接受对应来源检查范围；需要严格请求约束时使用支持该能力的后端 |
| Safari 闭合 Shadow DOM、不透明 frame 不具备同等 CDP 支持 | 使用受支持的页面上下文和目标；不自动降低策略 |
| Apple 原始 xctrace 附加/收尾及 XCTest 零帧问题未修复 | 明确选择兼容采集、独立原始帧区间或有效校准；缺测保持未评估，不补造原始字段 |
| BLE digitizer 不等于 iPhone 全局多指输入 | 报告通道保留为默认关闭实验选项；当前 iPhone 未形成触摸业务结果 |
| USB HID 软件实现不替代线缆与硬件验收 | 配套硬件到位后验证真实输入、多触点识别与断电释放 |
| 物理手机不具备完整系统隔离 | 显式使用独立 Android VM；UID 防火墙要求授权 root，不能代表整机沙箱 |
| 注册 Metal 区间、Android UID 估算电量不等于整机 GPU 或独占实际焦耳 | 指标保持其原始范围；精确硬件计量需要独立仪器和校准 |
| 任何单一设备或故障注入不代表所有生产环境 | 对目标系统、证书部署、物理外接屏、磁盘与网络故障单独验收 |

## 判定原则

缺少环境、观察不完整、目标不唯一、未知投递和缺测不能标为通过。权限撤销后停止输入，失败操作不自动重放。详见[判定与证据](quality.md)、[环境准备](environment.md)。
