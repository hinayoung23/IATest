# Web 控制台视觉与交互规范

## 定位

控制台采用企业产品官网式的表达：清晰的产品识别、强排版、大幅留白、宽幅章节与克制的动态效果。首页承担产品与工作空间入口，业务页承担高效操作；视觉变化不能掩盖实际状态或替代测试功能。

## 页面结构

顶部固定全局导航：概览、测试工作台、设备与环境、测试资产、执行与报告、项目知识、设置。测试资产统一覆盖 UI、接口、性能、安全、数据协议、无障碍与组合任务；契约、目标、计划和参考资料按实际存储来源展示，执行结果另行管理。右上项目菜单容纳项目切换、新建项目、语言及主题。窄屏导航展开为完整列表，所有入口支持键盘操作。

首页按顺序展示：主标题与两个真实操作入口、明确标注的工作流示意、当前项目真实数据、规划/执行/证据的滚动章节、工作区域入口。示意图不能冒充运行结果，不提供虚构通过率、任务或设备状态。

业务页统一为大标题、当前项目、模块导航和宽幅操作区。测试工作台按界面与交互、服务与数据、专项质量、自动化流程分组。界面与交互将 AI 目标探索作为主要创建路径，浏览器、移动和桌面默认展示目标与预期表单，先选择目标，再探索并独立回放，最后沉淀资产。手工步骤是显式切换的创建方式。其它场景先说明用途、前置条件和产出，再展示基础表单；完整 JSON 与专业配置折叠到高级区域。资产库提供统一分类、筛选、分页和可读详情，目标用例与固化计划保留关联及真实状态。设备检测以连接状态、工具状态和处理建议呈现，单个平台异常不吞掉其它设备结果。用细分隔线组织内容，表格和表单保留合理密度，不使用固定侧栏或大量装饰性指标卡。

## 视觉语言

- 默认白色背景、石墨色正文、灰阶次级文字、少量蓝色操作强调；深色主题使用中性黑灰。
- 使用系统字体，大标题随视口缩放；正文保持可读行宽和层级。
- 导航、按钮、表单、数据区有一致的焦点、悬停及禁用状态。危险操作继续使用明确的文字、颜色和二次确认。
- 图形为项目自有 CSS/SVG 工作流示意，不依赖外部字体、图片 CDN 或动画库。

## 动效

跨页优先使用 `@view-transition` 的浏览器原生同源导航过渡：顶部导航保持稳定，内容轻微位移并淡入淡出。保留完整页面请求、浏览器历史、POST 和现有表单处理，不使用抓取 HTML 后替换 DOM 的路由器。

首页章节使用 IntersectionObserver 一次性显现；工作流示意随自然滚动轻微位移，桌面章节使用 sticky 内容和当前章节指示。滚动事件被动监听，动画更新由 requestAnimationFrame 合并；隐藏标签页停止更新，不截获 wheel 或强制逐屏滚动。

系统设置 `prefers-reduced-motion: reduce` 时关闭位移和跨页动画。浏览器不支持新 API 时保留普通导航；无脚本时内容和全部导航仍可访问。动画只增强体验，不作为内容出现或功能可用的前提。

## 既有功能

后台任务面板、取消、进度、流式内容、设备预览和原生测试表单沿用既有应用逻辑。项目名、语言和主题跨页面保持；用户输入与未完成任务不能因为视觉切换而被静默重放。

## 实现位置

`web/templates/base.html` 提供外壳，`overview.html` 提供首页。`asset_library.py` 与 `application/asset_catalog.py` 汇集现有资产，`goal_workspace.py` 提供各平台的 AI 创建流程。`static/site.css` 和 `site.js` 管理视觉及动效，`app.css/app.js` 保留表单、任务、设备和业务操作。所有资源随包分发并由本机服务器提供。

页面提供五种语言、减少动态效果、可见键盘焦点和跳到主要内容入口。验收覆盖桌面/手机、深浅主题、导航前进后退、项目与语言切换、表单保存、后台任务、无脚本及减少动态效果。

技术参考：[View Transition](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@view-transition)、[减少动态效果](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)。
