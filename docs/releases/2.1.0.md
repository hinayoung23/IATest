# IATest 2.1.0

PyPI distribution: `iatest-framework==2.1.0` · CLI: `iatest` · Python: 3.11+

## 按项目和测试类型保存资产

接口、Web、桌面、Android、iOS、性能、安全、数据与协议等资产统一位于 `projects/<project>/assets/<type>/`。计划、目标探索用例、业务用例版本、安全规则、协议 Schema、设备配置和测量资料保存为可读 JSON/Markdown。运行结果和证据位于 `reports/<type>/`。

SQLite 保留可重建查询视图及内部状态。修改或删除资产文件会同步到查询结果；非法文件或重复身份会阻止读取，不会回退到旧缓存执行。通用入口和原生移动入口保留各自的计划标识空间。完整目录见[项目资产与目录](../guides/project-assets.md)。

## 升级与迁移

退出使用同一工作空间的旧版 IATest，再升级：

```sh
python -m pip install --upgrade "iatest-framework==2.1.0"
```

正常打开项目时迁移旧 API 目录和报告；首次访问通用或原生移动资产时，从旧数据库导出文件。旧目录、数据库和历史证据保留，新操作更新新结构。内容冲突时拒绝覆盖，并指出需比较的目标路径。

迁移标记独立于查询缓存，重建索引不会复活已删除资产。多文件提交保留恢复快照，进程中断后根据提交状态恢复；不要将整个 `.iatest/` 当作可丢弃缓存，也不要让旧版与新版同时写入同一项目。只读 MCP 支持新旧路径，不触发写入迁移。

本版本保留 2.0.1 的项目契约隔离修复；从更早版本升级、需要重新生成 API 用例时，另见[2.0.1 修复说明](2.0.1.md)。

## 兼容性与验证

修复 Windows 并发创建目录时普通路径和 `\\?\` 路径形式不一致导致的越界误报，保留跨项目符号链接保护。文档、CLI、Web、节点与执行器共用文件资产存储，旧证据地址继续可读。

回归覆盖旧库迁移、文件编辑和删除、用例版本、索引重建、并发写入、进程中断恢复、项目隔离及节点执行。发行流程验证 Python 3.11–3.14、Linux/macOS/Windows，以及仅安装基础 wheel 的 CLI、工作进程和 Web 控制台。
