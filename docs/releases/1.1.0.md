# IATest 1.1.0

PyPI distribution: `iatest-framework==1.1.0`; CLI: `iatest`.

## Changes / 更新内容

- Add constrained runtime test data, multiple samples, reproducible seeds and namespaces, cross-field contract validation, failed-input replay and partition sampling. Preserve fixed negative triggers and assertions.
- Add agent evaluation with offline replay and real models, durable sessions, completed-call recovery, full tool input/output contracts, cooperative deadlines and shared task budgets.
- Add configurable model routing and project test recipes without extending role permissions. Keep all independent quality judges and existing delivery gates.
- Add a read-only MCP stdio server and explicit HTTP MCP fixture integration, using existing sandbox, request-budget and cleanup controls.
- Add provider-independent token accounting, reversible audit evidence deduplication, authorized fact prefetch, conservative incremental reviews, task tool selection and adaptive input/output budgets. No provider prefix-cache integration or new production dependency.
- Fix assertion Schema/type contracts, semantic evaluation references, small-evidence reads, durable read-range serialization, audit cache invalidation and false requests for JSONPath assertions already guaranteed by a required JSON Schema field and fixed value.
- Make MCP and process-recovery regression subprocesses use explicit UTF-8 on Windows.

详细配置见 [运行时数据与 Agent 能力说明](../agent-data-evolution.md)、[用例格式规范](../case-format-spec.md) 和 [执行隔离说明](../sandbox.md)。

## Upgrade / 升级

```bash
python -m pip install --upgrade iatest-framework==1.1.0
```

保留现有 Markdown 用例和命令。已有固定数据继续使用；通过 `data_generation` 和 `samples` 显式启用运行时采样。新增生产依赖为零，Python 版本要求仍为 3.11 或更高。

Token 优化默认启用，设置 `agents.token_optimization.enabled=false` 可关闭。增量审计仅复用同模型、同规则和可信契约下已批准的高置信无问题基线；契约或脱敏内容变化、未知结构、影响范围过大等情况回退全量审计。角色与模型上下文限制继续生效，共享任务预算按配置启用。

```bash
iatest token-stats --project my-project --output token-usage.json
iatest agent-eval examples/evals/agent-baseline.json --trials 2
iatest mcp
```

评测样本和配方示例随源码包分发；真实模型评测须显式使用 `--live` 和现有模型配置。MCP 数据服务、业务实体准备和清理由项目方接入；MCP 不授予任意命令执行权限。

## Validation / 验证

- Local macOS / Python 3.14 regression: **468 tests passed**; offline agent baseline: **60/60**.
- Real model acceptance used existing Kimi, GLM and MiMo configurations. A single paired synthetic full-review trial used **76,613 → 55,756 tokens (-27.22%)**, with **9 → 3 model calls**. Both candidates passed the unchanged delivery policy; elapsed time did not improve.
- A local edit passed incremental review; a deliberately invalid HTTP 500 assertion against a trusted HTTP 200 contract was detected as critical by all three judges. Two real GLM design tasks passed compilation.
- Earlier synthetic fixture failures were retained and corrected before the paired acceptance. These trials do not establish savings or long-term stability for every project.

发布沿用 push/PR 的 Linux、macOS、Windows 测试矩阵，以及 Release 工作流的 Python 3.11–3.14 测试、wheel/sdist 构建、元数据检查和 PyPI Trusted Publishing。真实 Docker 端到端业务运行仍需在具备 Docker 的环境验证。

```bash
python -m pytest -q
python -m build
python -m twine check dist/iatest_framework-1.1.0-py3-none-any.whl dist/iatest_framework-1.1.0.tar.gz
```
