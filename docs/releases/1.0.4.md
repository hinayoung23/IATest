# IATest 1.0.4

PyPI distribution: `iatest-framework==1.0.4`; CLI: `iatest`.

## Changes / 更新内容

- Add complete JSON Schema assertions, recursive OpenAPI definitions and constraint-checked sample generation. Fix missing-header assertions and business-rule change detection.
- Add JSON/CSV/matrix datasets, reproducible seeds, environment/identity selection, stable CI sharding, failed-case reruns and JSON/JUnit exports with meaningful exit codes.
- Add Bearer/OAuth2 authentication, proxy/CA/mTLS settings, independent case cookies, polling, safe retries, cancellation and execution deadlines.
- Add fixture checks, installed-plugin assertions/hooks/adapters, resource mutexes, execution provenance, coverage evidence and incremental generation caches.
- Add default file/network access policies, isolated process workers and an optional Docker backend with bounded inputs/results, checkpoints and forced termination.
- Extend shared redaction and regression coverage; add Linux/macOS/Windows push/PR testing and Windows operation locks.

对应使用方式见 [框架能力说明](../framework-improvements.md)、[执行隔离说明](../sandbox.md) 和 [用例格式规范](../case-format-spec.md)。

## Upgrade / 升级

```bash
python -m pip install --upgrade iatest-framework==1.0.4
```

Markdown 用例格式和原有命令保持兼容，新增生产依赖为 `jsonschema>=4.23,<5`。

默认 `sandbox.mode=policy`：当前配置环境和显式 CLI base URL 已授权，额外鉴权、Fixture、文档来源须配置 `sandbox.allowed_origins`；用例文件和数据集遵守 `read_paths`/`denied_read_paths`。插件需同时配置 `plugins` 与 `sandbox.allow_plugins=true`。旧项目应按实际用途授权所需范围。

普通进程提供故障和超时隔离，不能限制任意 Python 插件的宿主机权限；运行不可信插件应使用容器。容器模式要求已准备 Docker、镜像和 internal 测试网络，默认网络为 none；运行失败时不会自动降低隔离级别。

强制中断不保证远端 cleanup 完成。`{{iatest_namespace}}` 需由测试服务实际用于数据隔离，并配合独立测试账号、幂等清理或 TTL。

## Build / 构建

```bash
python -m pytest -q
python -m build
python -m twine check dist/iatest_framework-1.0.4-py3-none-any.whl dist/iatest_framework-1.0.4.tar.gz
```

GitHub Release 触发既有发布工作流，在 Python 3.11–3.14 测试后构建 wheel/sdist，经 PyPI 环境审核和 Trusted Publishing 发布。Docker 真实运行需另行在具备 Docker 的环境验证。
