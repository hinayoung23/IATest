# Web 控制台设计提示词

设计一个本地接口自动化测试工作台，面向测试开发和后端研发。整体风格要清爽、专业、偏 SaaS 工具，避免营销页和装饰性插画。

页面包括：

- 仪表盘：展示当前项目、接口数量、用例数量、上次执行通过率、配置入口。
- 接口信息页：展示接口文档来源、接口列表，支持新增、编辑、删除接口。
- 用例信息页：展示用例编号、名称、等级、上次执行时间、上次执行结果，并支持选择冒烟/全量执行。
- 测试报告页：分页展示报告标题、计划执行时间、执行用例条数、成功率、详情和删除入口。
- 报告详情页：只读展示单份报告明细。
- 配置中心：展示主控模型、用例生成模型、结果分析模型，以及用例生成策略和执行策略。

布局要求：

- 左侧固定导航，右侧为主内容区。
- 顶部显示当前页面标题和项目切换控件。
- 仪表盘使用指标卡片，列表页使用紧凑表格。
- 主操作按钮清晰，危险操作使用红色并需要二次确认。
- 表单元素对齐，输入区和表格留足间距。
- 响应式支持窄屏单列布局。
