# 性能、安全与无障碍

## 性能

单机引擎支持两种负载：

- `arrival_rate`：按照单调时钟安排到达时间，`rate` 是目标每秒请求数，`users` 是最大在途并发。没有可用工作线程或调度延迟过大时记为 dropped，不建立无界排队。结束后排空已发请求。
- `users`：每个用户串行请求，支持 `think_seconds`，测量完成量随被测服务时延自然变化；不能把它当成固定到达率。

每用户有独立 HTTP 会话，支持可选 `setup/teardown`，准备失败阻止发压；取消后保留所有用户共享的 5 秒清理时限及 `users*6` 请求额度，清理未完成会记录错误。`cleanup_requests` 单列，`requests` 包含清理。请求数据支持 `{{namespace}}/{{user}}/{{iteration}}/{{random}}`，保存 seed 和运行 namespace。命名空间每次不同，seed 控制随机序列；不会在每个请求内调用模型。

限制为最多 128 并发、600 秒、100,000 个目标/样本。保留全部有限样本并按 nearest-rank 计算 P50/P95/P99，包含失败尝试，禁止平均分位数。报告实际请求数、错误率、达成 RPS、丢弃量、调度延迟、最大在途和生成器进程 CPU 时间；RPS 的测量窗口不包含准备/清理成本。CPU 指标包含同进程其他工作，不是完整的压测机饱和诊断。

请求质量门禁支持 `p95_ms/max_error_ratio/min_rps/max_dropped_ratio`，多步骤事务另有事务时延、错误率及 TPS 门禁。出现丢弃而未声明丢弃率门禁时返回无法确定，防止因发压不足误判服务达标。请求时延包含客户端请求到完整响应消费，不等于服务器 CPU 时间或浏览器渲染性能；事务指标单独统计。已支持配对节点的局域网分布式发压，并通过真实 Mac—Windows 小规模功能验收；不支持无限时长/无限样本，不自动给出容量结论。多步骤事务、分布式份额及验收范围见[业务测试说明](business-testing.md)。

## 安全

必须声明授权来源、规则、身份和对照资源。仅评估明确配置的检查，未执行项记为 not_assessed；没有发现不代表已完成所有漏洞扫描。既有三个对照规则是：

- `authorization`：所有者 2xx 响应必须包含预期资源标记，再用独立身份请求同一资源。对照身份返回同一资源的 2xx 才形成越权发现；明确拒绝且不包含资源才通过，其余返回无法确定。两身份不能使用相同凭据，各自 Cookie 会话隔离。
- `contract_mutation`：基线输入必须满足 JSON Schema，删除必填字段、改变类型或加入额外字段后的输入必须实际违反契约。基线成功，非法输入仍获 2xx 时记录契约校验差异；4xx 视为拒绝，5xx/重定向不作为校验通过证据。写请求需要显式 `allow_mutation:true`，不自动清理业务数据。
- `response_headers`：检查显式声明的响应头。非空预期值采用去除首尾空白后的精确匹配，空预期表示只要求存在；这是响应策略差异，不自动声称存在可利用攻击。

身份凭据建议写为 `{"Authorization":{"$env":"TEST_OWNER_AUTH"}}`，环境变量值包含所需 Bearer 前缀。框架不修改密钥。发现包含规则、复现请求、身份名称、资源标记、严重性与去重 ID；保存及展示使用统一脱敏。另提供显式范围/页数/深度的 HTML 爬取、版本化声明式规则库及有对照的验证链，见[扩展覆盖说明](../reference/capabilities.md)；不承诺无限全站、任意代码利用链或所有 OWASP 类别。

## 客户端指标

客户端计划可结合浏览器或真实移动旅程，使用显式阈值、数据来源和质量状态。Android 可读目标 UID 网络与系统估算电量；iOS 可读注册 Metal 区间及显式采集指标。

| 指标 | 含义 |
|---|---|
| `app_metal_gpu_busy_ratio` | App 显式注册并完成的 Metal 区间并集/观察窗口，不是整机 GPU |
| `gpu_allocated_memory_kb` | App 已注册 Metal device 的分配内存 |
| `app_estimated_battery_mah` | 唯一 UID、未充电条件下的系统模型估算，不是独占实际焦耳 |
| 设备电量、温度、电功率 | 对应设备提供的快照，不是 App 独占消耗 |
| App/设备网络计数 | 保留 UID 或网卡的实际范围，不能混用 |

缺测不填零。两个快照的较大值不宣称整个期间峰值。iOS 原始采集与校准见[iOS 性能](ios-performance.md)。

## 安全规则与无障碍

安全规则库是有版本和摘要的声明式资产，爬取明确限制 roots、路径、页数和深度。验证链需基线、身份和内容/资源谓词，状态码或 CVE 版本不能单独证明漏洞；写请求另需明确允许。

无障碍提供有限自动规则及 WCAG 2.2 清单，未自动评估的条款保持需要人工复核。人工记录绑定页面/构建摘要、条款、审核人、证据与理由；过期、篡改或不完整扫描阻止合规通过，不提供全自动认证。

AI 分析只解释已有事实，不能改写判定或把一次负载差异直接当作统计显著回归。详见[证据规范](../reference/quality.md)。
