# Web 控制台

```sh
iatest web --project my-project
```

访问 `http://127.0.0.1:8765`。控制台只监听本机回环地址。

## 导航与工作空间

顶部导航按使用任务组织为七个工作区：概览、测试工作台、设备与环境、测试资产、执行与报告、项目知识、设置。右上项目菜单用于切换项目、新建项目、语言和深浅主题；窄屏使用导航按钮展开同一组入口。

首页的工作流图是产品示意；测试计划数、设备配置数、API 用例数及知识数来自当前项目，不用示例值冒充实际状态。

## 常用工作流

| 工作 | 操作位置 |
|---|---|
| 选择测试场景、查看用途/准备条件/产出 | 测试工作台 |
| 浏览器、桌面或手机操作测试 | 测试工作台 → 界面与交互 |
| HTTP 请求、CSV 数据质量、消息协议 | 测试工作台 → 服务与数据 |
| 服务性能、客户端性能、安全、无障碍 | 测试工作台 → 专项质量 |
| 组合计划、远程运行、版本任务 | 测试工作台 → 自动化流程 |
| 检测设备、保存配置、调试控件、管理安装包或执行节点 | 设备与环境 |
| 按类型管理文档、目标用例、计划、规则与指标资料 | 测试资产 |
| 查看 API 报告、类型化测试结果、移动结果与证据分析 | 执行与报告 |
| 确认知识、解决冲突、查看来源与审计 | 项目知识 |
| 配置模型、运行环境、执行策略、夹具和治理 | 设置 |

## 创建测试

测试工作台的界面与交互入口以 **AI 目标探索** 为主要创建方式：选择浏览器、Android、iPhone/iPad 或桌面应用，填写业务目标和具体通过条件，再开始探索。Web 填开始网址，手机选已有设备配置，桌面填写系统、进程与应用身份；常规场景无需编写上下文 JSON。

AI 开始探索后会调用已配置模型并实际操作目标，再用新会话独立回放至少两次。稳定复现的用例关联可运行计划；不稳定、缺条件或观察不完整的结果保留候选状态和原因。各平台入口均可切换到“手工编排步骤”，手工保存只创建计划，运行按钮才执行。完整上下文、复杂协议和专业采集配置在高级区域。

## 统一资产库

所有测试类型使用同一套分类、筛选、详情和复用入口；API 文档和用例与其它类型资产并列管理。

| 测试类型 | 已有资产 |
|---|---|
| UI 测试 | AI 目标用例、版本化业务目标、浏览器/桌面/手机计划 |
| 接口测试 | 接口契约、API 用例、HTTP 请求计划 |
| 性能测试 | 负载与客户端采样计划、导入指标、采集校准 |
| 安全测试 | 授权验证与扫描计划、版本化安全规则库 |
| 数据与协议 | 数据质量与消息计划、Protobuf 描述符 |
| 无障碍测试 | 自动检查计划、人工复核资料 |
| 组合与版本任务 | 工作流、远程计划、版本验证任务 |

支持按名称、标识、平台及资产类型筛选，并分页展示。空类别保留创建入口，不显示示例值。资产详情展示目标、状态、步骤或门禁，完整内容在高级区域。AI 用例与固化计划互相关联；可运行计划提供显式运行和编辑入口。执行记录与分析仍在“执行与报告”中管理。

## 其它场景创建

数据质量表单接收带列名的 CSV，支持列唯一性、空值和数量检查；空单元格按 null 处理。协议表单支持 HTTP 状态码、WebSocket 收发和 MQTT 订阅/发布/收回检查；gRPC 等复杂交互在高级配置中维护。桌面和无障碍表单分别填写目标控件/结果与页面检查规则。

组合流程可以勾选已有计划，按显示顺序串行执行；手动顺序、独立分支和清理计划可另行设置。客户端性能与远程运行选择已有子计划，不需要复制整份计划。版本任务填写构建和环境并选择计划。

## 移动测试

1. 在“设备与环境 → 设备配置”点击检测。结果显示设备状态、工具是否安装及处理建议；单个平台服务异常时保留其它检测结果。发现设备不代表驱动或业务 App 已验收。
2. 将检测到的设备用于新配置，填写目标 App 包名/Bundle ID。首次使用先按构建说明准备原生组件。
3. 打开会话，在“设备调试”中取得原生控件标识。
4. 到“测试工作台 → 界面与交互”选择 Android 或 iPhone/iPad，选择设备配置，描述业务目标和通过条件，开始 AI 目标探索。已有明确操作步骤时切换“手工编排步骤”，添加操作和最终断言。
5. 在“测试资产 → UI 测试”审阅已保存的目标用例与计划，再主动运行。统一引擎执行的计划在类型化结果查看，独立移动会话执行的计划在移动端结果查看。AI 探索需要配置模型和可用原生驱动。

旧的 `/interfaces`、`/cases`、`/reports`、`/testing?tab=…`、`/mobile?tab=…` 地址仍可直接访问，页面会显示对应工作区导航。全部返回首页的入口统一称为“返回概览”。

长任务在后台继续执行，可从任务面板查看进度或取消。同类活动任务会阻止重复发起。关闭提示不取消任务，任务完成也不等于测试通过。

## 页面与可访问性

页面使用原生同源导航过渡和自然滚动章节；不支持动画的浏览器正常导航。系统开启减少动态效果后关闭位移与切页动画。键盘可使用顶部「跳到主要内容」，Tab 移动焦点，Escape 收起导航和项目菜单。

所有测试依然需要明确授权和独立断言。控制台外观不改变[能力边界](../reference/capabilities.md)或[判定规则](../reference/quality.md)。
